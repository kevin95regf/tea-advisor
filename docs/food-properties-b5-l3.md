## 1. 19 条逐条结论

### 1.1 ③ 无源可引 · 语料无条目（14 条）

判据：50 号文件 §5.1「只有该物本身是条目名、且所在条目含【性味／气味／性能】字段，才算有据」。
**「被提及」≠「有记载」。**

| 条目 | 结论依据 |
|---|---|
| 苹果 `pingguo` | §5.2 明列 ＋ **§6.1 专章判 C**（本草近似物「柰」「林檎」均非现代苹果，三家说法自相矛盾，不得顶替） |
| 柠檬 `ningmeng` | §5.2 明列（近代／外来水果） |
| 草莓 `caomei` | §5.2 明列 |
| 芒果 `mangguo` | §5.2 明列 |
| 辣椒 `lajiao` | §5.2 明列（纲目拾遗未见「辣茄／番椒」条目） |
| 豆芽 `douya` | §5.2 明列「绿豆芽」（主食加工） |
| 酸奶 `suannai` | §5.2 明列（蛋奶类） |
| 豆浆 `doujiang` | §5.2 明列（饮品类） |
| 咖啡 `kafei` | §5.2 明列（饮品类；可可、啤酒、豆浆同列） |

| 山竹 `shanzhu` | 实测 0 命中（含别名「莽吉柿」）；同上 |
