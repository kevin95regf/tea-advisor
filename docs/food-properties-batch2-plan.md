## 0. 结论先行：三处更正

### 更正一：「食药物质组」这个批次不成立 —— 全表只有 4 条命中

按你的口径（蔬菜/调味/水果 ∩ 106 种食药物质目录）逐条匹配，结果：

| 范围 | 命中数 |
|---|---|
| 全表 146 条 ∩ 食药物质目录 | **4 条** |
| 其中落在蔬菜/调味/水果三类 | **2 条**（姜、龙眼） |

四个命中项：**海带**（目录名「昆布」）、**姜**、**龙眼**（目录名「龙眼肉」）、**山楂果**（目录名「山楂」），全部属 2002-51 批次。

**为什么这么少，不是执行问题**：食药物质目录收录的是**药材与调味香料**（丁香、八角茴香、山柰、荜茇、化橘红……），而食性表是**日常食材与菜肴**（白菜、米饭、饺子、奶茶）。两者的交集天然极小。而且**目录只给「既是食品又是中药材」的合规身份，不含四气** —— 它根本不能作为四气依据（这一点写进了 `sources.json` 的 `hard_rules`）。

### 更正二：但「蔬菜/调味/水果」作为第一批是对的 —— 理由不同

支撑这一批的强来源不是食药物质目录，而是 **50 号文件（TCM.Skill）的 §2 A 档 / §3 B 档 / §5.3 别名索引**。全表分层实测（按「该条可取的**最强**来源」计，一条只落一层）：

| 层 | 来源 | 条数 |
|---|---|---|
| **① 官方** | 《中国药典》2020 一部 | **3**（龙眼、山楂果、姜） |
| **① 官方** | 食药物质目录（仅合规身份，**无四气**） | 1（海带） |
| **② 通行** | 《中医饮食营养学》§2 A 档 | 35 |
| **② 通行** | §3 B 档（可核但有冲突） | 1（西瓜） |
| **② 通行** | §5.3 别名索引（有据，勿误判为缺口） | 6 |
| | **有来源可引合计** | **46** |
| **③ 无源** | 50 号文件 §5.2 真无据清单 | 16 |
| **③ 无源** | 50 号文件与目录均无条目 | 84 |

> 一条只落一层（按最强来源计）。海带另有 §5.3 的四气证据（昆布 寒），因目录身份排在前而计入①。

**有来源可引共 46 条**（①4 + ②42），其中 **33 条属蔬菜/调味/水果三类**。三类共 46 条，即 **72% 的三类条目有来源可引** —— 这是全表覆盖最好的区段。**建议第一批就用这 33 条。**

### 更正三：官方层对食物几乎零覆盖

口径甲的第一档（官方）在食物四气上基本失效：卫健委/营养学会的食养指南按**疾病/人群**编写，性味数据只覆盖**食药物质**；药典覆盖的是**药材**。全表能沾到官方的**只有 4 条**：海带、姜、龙眼、山楂果 —— **正好就是「食药物质目录 ∩ 食性表」的那 4 条**，其中 3 条另有药典原文。你已决定不做联网试找，此处用分层记录留痕即可。

## 2. 核对方案（口径甲落地）

### 2.1 来源分档与用法

| 档 | 来源 | 强度 | 用法 | 硬约束 |
|---|---|---|---|---|
| ① | 《中国药典》2020 一部 | 最高 | 可直接采用 | **药品**标准，用作食品参考属跨用途；须注明 |
| ① | 食药物质目录（106） | **仅合规身份** | **只用于证明合规身份，不作四气依据** | 目录不含四气 |
| ② | 《中医饮食营养学》（50 号 §2 A 档） | 次高 | 可直接采用，**引原文列** | **非官方标准**；行号绑定语料版本 |
| ② | 《中药学》七版 / 《本草纲目》（§5.3） | 核对方 / 溯源用 | 取用时须写明是谁的书 | 纲目为明清前体系，**只能定「古籍怎么说」** |
| ③ | 无 | —— | 标 `null` + 「无权威来源，凭专业判断」 | **不得用通行表述伪装权威依据** |

### 2.2 逐条流程

```
对每条：
  1. 命正名 → 取 A 档（50 号 §2）
  2. 正名无 → 查 §5.3 别名索引（"查不到≠缺口"，很多是别名问题）
  3. 别名无 → 查 §5.2 C 档真无据清单 → 判 no_basis
  4. 都不在 → 层③「50 号文件与目录均无条目」
  5. 命中多个 → 按 ①药典 > ②A档 > ②§5.3 取基准；全部来源列出备查
  6. 判层：一致→① / 冲突→② / 无源→③ / 表内自相矛盾→④
```

**C 档的关键区分：**「被提及」≠「有记载」。50 号 §5.1 明确：只有该物本身是条目名、且条目含【性味/气味/性能】字段才算有据。例：**苹果**在 7 部语料里出现过，但全是散文式提及，一律判 C。

**制品不得继承原料四气**（50 号 §5.2 附注）：菊花有据（微寒），但**菊花茶是冲泡制品、本库无条目**。同类：冰糖可借「石蜜」、**红糖无对应条目**；绿茶/红茶有方向性描述（§4.5 B 档）、**乌龙/普洱无**。

### 2.3 第 1.2-④ 四层分层规则

| 层 | 内容 | 处理 |
|---|---|---|
| ① | 来源与现状一致 | 审核人可 `approved` |
| ② | 来源与现状冲突 | 进问题清单，**不得直接 approved** |
| ③ | 无源可引 | 标「无权威来源，凭专业判断」 |
| ④ | 表内自相矛盾 | 属 bug，**先修**（见 §4） |

## 4. 新发现：④ 层第 4 类矛盾 —— 别名跨物种

核验第一批时跑出来的**新一类表内矛盾**（阶段一的 3 类没覆盖到）：

| 条目 | 问题 | 依据 |
|---|---|---|
| **蘑菇**（`mogu`，现=平） | 条目名「蘑菇」的**别名同时含两个不同四气的物种**：`别名「蘑菇」→ 蘑菰 寒`（纲目 23487）、`别名「香菇」→ 香蕈 平`（S1:1887）。取到哪个值取决于匹配路径 —— 与 ④-1「炸鸡」同型，但**这次两个值都不是错的，是条目本身把两个物种合了** | 50 号 §5.3 两行 |

**与 ④-1 的区别**：炸鸡是**别名污染**（把不属于自己的名字挂上去，删掉即可）；蘑菇是**条目粒度错误**（一个条目代表两个物种），删别名解决不了 —— 要么拆成两条，要么明确它代表哪个物种。

**已拍板（2026-09-17）**：**拆两条**（蘑菰/香蕈 是两个物种）。方案与「金针菇/杏鲍菇/平菇 怎么归属」的待定点见 `docs/food-properties-batch2-confirm.md` §1.3。（属数据改动，D5 执行）
