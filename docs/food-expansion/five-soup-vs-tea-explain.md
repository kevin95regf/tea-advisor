## 总对照：茶饮 vs 这五类食疗汤

### 产品里「茶饮」实际指两层（别混）

| 层 | 数据 | 角色 |
|---|---|---|
| **A. 食性表里的茶饮名** | `food_properties.json` → `tea_drinks.items`（约 18 条：茉莉花茶、菊花茶、姜茶…） | 帮 Agent1 **认出用户喝了什么**，给寒热标签；**不**负责出搭配剂量 |
| **B. 推荐侧的「日常茶饮」** | `herbs.json` 白名单 + Agent2 / `fallback_recommend` | 在白名单内给 **1–3 条冲泡/轻煮搭配**；≤4 味、有 `max_daily_g`、**禁止方剂名与君臣佐使**（`SPEC.md` §1；`agent2_system.md` 硬性边界 2） |

下文「与茶饮比」默认对比的是 **B 层推荐体验**；A 层只在「银耳」等跨表时顺带提到。

已落地的 **四神汤 / 姜枣茶**（`soup_templates.json`）是第三种东西：**策展型食疗模板**——人工钉死组成与家庭约量文案，`kind=food_therapy`，**刻意未**接进 Agent2 拼方。下面五条若将来落地，应走同一哲学，而不是让模型自由加减成「开方」。

### 性质差异（场景 · 形态 · 寒热 · 跨表 · 像不像开方）

| 维度 | 既有茶饮推荐（B） | 本批五条食疗汤取向 |
|---|---|---|
| **场景** | 饭后/日常「泡一杯」调养方向 | 家常甜汤、清补煲汤、轻煎饮；更像厨房药膳 |
| **形态** | 保温杯焖泡为主；部分坚实质地改「煮 20–30 分钟」仍属饮片茶 | 久炖甜汤 / 鸡汤 / 多味煲汤；银耳、鸡肉是**食材角色**，不是「第 N 味药」 |
| **寒热叠加** | 通常 2–4 味饮片，护栏偏「别像方剂」 | 多味同向叠加更明显（清补凉一串凉润；芪枣鸡一串温补），体质错配代价更大 |
| **跨 food + herb** | 推荐输出几乎只出 herbs | **银耳、鸡肉**在食物表；饮片在 herbs——模板必须允 `food_id`，或先接受「猪肉/鸡肉」桥接文案 |
| **像不像「开方」** | 结构上压成日常茶饮；禁方名 | 带「汤/饮」名更容易被看成方剂；须用 **取向 / 白名单版 / 自拟食疗名**，并禁止挂补中益气、银翘等经方名 |

### 开方 / 推荐难度差异

| 维度 | 茶饮推荐 | 五条食疗汤 |
|---|---|---|
| **辨证要求** | 以本餐信号 + 体质方向粗调；高风险人群直接空推荐 | 补气鸡汤、养阴清补凉对「谁能喝」更敏感；仍**不能**做成望闻问切式开方 |
| **剂量敏感** | 单味封顶 + 单次 ≤4 味 + 总量意图「不像方」 | 厨房约量 + 单味 `max_daily_g`；**禁止**抄门诊汤剂 g 数；鸡汤里黄芪/党参易被用户自行加量 |
| **禁忌人群** | 孕哺儿童慢病服药 → 空推荐 | 另增：**2023-09 黄芪/党参特殊人群不推荐**；**麦芽回乳**；山楂孕妇慎；凉润叠加对阳虚/脾虚 |
| **白名单边界** | Agent2 只能选候选清单 | 模板组成必须事先钉死；市售「清补凉」包材常夹目录外味 → **拒绝未知包** |
| **文案风险** | 禁治疗/方剂词 | 禁「本方即补中益气/银翘」；当归类已有「避调经」先例；鸡汤条目勿写成处方汤头 |

### 总表：五条难度档（开方/产品落地难度）

| # | 名称 | 难度 | 一句话原因 |
|---|---|---|---|
| 1 | 银耳莲子百合汤取向 | **低** | 出处强、组成已在库、偏润燥甜汤；主要只是模板要支持 `food_id`（银耳） |
| 2 | 芪枣鸡汤取向 | **中** | 单味已齐，但须久炖+鸡肉桥接+黄芪特殊人群+**禁挂补中益气** |
| 3 | 参芪大枣饮取向 | **中** | 无肉更轻、可与上条共模板族；双补气公告与「补虚」文案仍要闸 |
| 4 | 清补凉白名单版 | **中** | 工程上要钉死味数、拒市售未知包；多味凉润叠加，阳虚/痰湿易踩雷 |
| 5 | 山楂麦芽消食饮 | **高** | 组成最简单，但**麦芽哺乳回乳必须产品级硬闸**（另含山楂孕慎）；不过闸等于伪安全 |

说明：难度评的是「相对现有茶饮链路，做成**可自动/半自动推荐**有多难」，不是药效强弱。五条都仍属 **A 层食疗**，**不是**补中益气汤、银翘散等门诊经方。

## 逐条详解

### 1. 银耳莲子百合汤取向 — 难度 **低**

#### 是什么 / 文献要点

家常润燥甜汤取向：银耳为羹底，配莲子、百合（可再加冰糖等厨房调味，产品不必当「药」入库）。

可核验出处（已见于文献候选表，此处不扩写未核页）：

- 广东省中医药局百合科普页提及「银耳莲子百合汤」类做法；  
- 国家中医药管理局秋季相关发布会语境中有「银耳莲子羹」类饮食建议。

#### 建议组成（标是否在库）

| 角色 | id | 名称 | 表 | 在库 | nature（库内） |
|---|---|---|---|---|---|
| 食材 | `yiner` | 银耳 | foods | **是** | neutral |
| 饮片 | `lianzi` | 莲子 | herbs | **是** | neutral；`requires_cooking` |
| 饮片 | `baihe` | 百合 | herbs | **是** | cool；`requires_cooking` |

可选厨房项：冰糖/清水——不必进 herbs。不建议为「更像药方」再塞麦冬/玉竹进本条（那是清补凉方向，见第 4 条）。

#### 与泡茶 / 代茶差在哪

| | 典型茶饮搭配 | 本条 |
|---|---|---|
| 煮法 | 焖泡或短煮出味 | 银耳须泡发久炖成羹；莲子/百合亦需煮软（库内已标须煮） |
| 用时 | 数分钟～半小时饮品 | 常 1 小时量级甜汤；一次一碗，不是续水茶 |
| 食材角色 | 几乎全是饮片 | **银耳是食物**，寒热来自食性表，不是饮片 `max_daily_g` 逻辑 |

#### 寒热与体质风险

- 整体偏 **平～微凉润**（百合 cool + 银耳/莲子平）。  
- 较适合口干、燥感、想吃甜汤时的**饮食参考**；风寒咳嗽、脾胃虚寒、便溏（百合 caution）不宜当默认夏冬通吃。  
- 相对茶饮：凉润叠加弱于「清补凉」长名单，但仍比「陈皮山楂焖泡」更黏腻甜，痰湿腹胀者慎。

#### 为何难度是「低」；落地前要补什么

- 组成闭环已在；政府科普向出处相对清楚；不像经方。  
- 落地前（**本轮不做**）：`SoupTemplate.components` 允 `food_id`；caution 复用百合/莲子；文案写「食疗甜汤取向」，勿写治疗肺燥处方。  
- **方名**：可用「银耳莲子百合汤」——大众本就是食疗名；不必改成隐晦名。

#### 明确不是

不是养阴清肺汤、不是百合固金汤，也不是任何门诊润肺方加减。

### 2. 芪枣鸡汤取向 — 难度 **中**

#### 是什么 / 文献要点

气虚清补向的**家常鸡汤**习惯：黄芪 + 红枣（± 党参）配鸡肉同炖。文献候选指向四川中医药局科普转载式稿、三明市卫健委等页的「黄芪炖鸡 / 参芪大枣」类叙述——作**饮食科普**，不是《方剂学》补中益气汤原文执行。

#### 建议组成

| 角色 | id | 名称 | 表 | 在库 | 备注 |
|---|---|---|---|---|---|
| 饮片 | `huangqi` | 黄芪 | herbs | **是**（pending） | warm；须煮；max 20 g；2023-09 特殊人群不推荐 |
| 饮片 | `hongzao` | 红枣 | herbs | **是** | warm |
| 饮片（可选） | `dangshen` | 党参 | herbs | **是**（pending） | neutral；同上公告；不宜藜芦 |
| 食材 | `jirou` | 鸡肉 | foods | **是** | warm |

无独立「鸡架/鸡汤」条目时，用 `jirou` 桥接即可，文案写「鸡肉或土鸡块煲汤」。

#### 与泡茶差在哪

- 茶饮里黄芪即使出现，也是「煮饮片」；这里是 **肉汤载体**，脂肪与药味同出，用户体感是「补汤」不是「花草茶」。  
- 用时、火候、盐油都是厨房变量——产品只能给取向与单味封顶，不能假装精确方剂煎法。  
- 寒热：温补同向（黄芪温 + 枣温 + 鸡温），阳虚畏寒饮食场景贴合度高，但**实热、外感发热、气滞湿阻**滥补风险高于普通消食茶。

#### 寒热与体质风险

- 偏温补气；湿热、痰湿腹胀、感冒发热期间不宜当默认推荐。  
- 孕妇、哺乳、婴幼儿：黄芪/党参公告口径 → **应与高风险闸门同级或更严**，不能只靠 Agent2 提示词。  
- 红枣含糖：血糖偏高控制分量（与姜枣茶同理）。

#### 为何「中」；落地前要补什么

- 难在合规与文案，不在缺味。  
- 必须：**禁写「补中益气汤」**；显示名用「芪枣鸡汤取向」或「黄芪红枣炖鸡（食疗）」；`review_status` 保持 pending 至人工批。  
- 模板规则：鸡肉 `food_id`；黄芪/党参 caution 入库级；可选「无党参版 / 有党参版」两个 template id，避免一次堆太像方。  
- 与茶饮护栏关系：若误接进 Agent2 自由拼方，温补鸡汤极易突破「日常茶饮」认知——只宜只读模板或强白名单 template id。

#### 明确不是

**不是补中益气汤**（缺人参/白术/升麻/柴胡等，且不得用党参顶替后冒充原方）。不是四君子汤。

### 3. 参芪大枣饮取向 — 难度 **中**

#### 是什么 / 文献要点

与第 2 条**同源科普链**上的「参芪大枣汤/饮」：黄芪 + 党参 + 红枣，可轻煎或作甜饮，**不一定**带肉。文献候选表写明与芪枣鸡汤可合并为「清补气虚」模板族。

#### 建议组成

| id | 名称 | 在库 | nature |
|---|---|---|---|
| `huangqi` | 黄芪 | 是 | warm |
| `dangshen` | 党参 | 是 | neutral |
| `hongzao` | 红枣 | 是 | warm |

全 herbs，**无 food 依赖**——比鸡汤版工程更简单，但公告与文案难度同级。

#### 与泡茶差在哪

- 形态上最接近「须煎煮的代茶」，但仍是**命名食疗组合**，不是 Agent2 临时起的「黄芪党参红枣饮」自由标题（若将来只允许 approved 模板名，须把本 id 列入白名单）。  
- 相对鸡汤：少温热肉类，负担略轻；相对菊花枸杞焖泡：仍是补气向，久服/加量动机更强 → 剂量文案要更克制。

#### 寒热与体质风险

同第 2 条的参芪公告与温补风险；无鸡则温性略减，但仍非清凉茶。外感表实、气滞湿阻不宜滥补。

#### 为何「中」；落地前要补什么

- 可与芪枣鸡汤共用 caution 包与「禁经方名」规则，产品上建议 **一个模板族两个展示入口**（有鸡 / 无鸡），避免用户以为是两张不同处方。  
- 特殊人群公告 caveat 必须进模板 `cautions[]`，并与全局孕哺闸门一致。  
- 落地前确认：是否允许在 title 出现「参芪」——可以，但旁边要有「食疗取向、非药品」；**禁止**「补中益气」「益气聪明」类方剂/功效夸张词。

#### 明确不是

不是补中益气汤，不是独参汤，不用人参替换党参来「增强」。

### 4. 清补凉白名单版 — 难度 **中**

#### 是什么 / 文献要点

岭南语境常见的养阴生津类甜汤/煲汤组合。粤中医局「清热生津汤」类科普可见银耳、沙参、玉竹、百合、莲子、山药等写法。产品侧只能做 **固定白名单组成**，不能识别市售「清补凉料包」里每味是否合法。

#### 建议组成（项目可钉死的一版示例）

以下取**库内已有、偏养阴润燥**的交集（具体味数产品拍板时可 4–5 味，避免堆成方剂感）：

| id | 名称 | 在库 | nature | 备注 |
|---|---|---|---|---|
| `yuzhu` | 玉竹 | 是 | cool | 须煮 |
| `maidong` | 麦冬 | 是 | cool | 可泡可煮 |
| `baihe` | 百合 | 是 | cool | 须煮 |
| `lianzi` | 莲子 | 是 | neutral | 须煮 |
| `shanyao` | 山药 | 是 | neutral | 须煮 |
| （可选食材）`yiner` | 银耳 | 是 | neutral | 与第 1 条交叉时，产品应避免两个模板过度重复 |

**沙参**：若未在当前 `herbs.json` 白名单，**本白名单版不得擅自加入**；缺则宁可减味，也不引入未核目录外药。

市售包常夹的非目录/未入库味 → 模板策略：**只认本站 component 列表**；用户上传「清补凉包」照片或自由文本 → 拒绝自动展开。

#### 与泡茶差在哪

- 茶饮推荐很少一次给 5 味同向凉润；清补凉天然「一锅多料」，更像药膳汤料。  
- 煮法：甜汤/广式煲汤时长；不是续水花茶。  
- 与第 1 条关系：银耳莲子百合是**短名单润燥甜汤**；清补凉是**扩容白名单养阴锅**——产品上应分两条，避免用户以为「清补凉 = 随便加」。

#### 寒热与体质风险

- 多味 **cool** 叠加（玉竹、麦冬、百合），整体偏凉润。  
- 阳虚、脾胃虚寒、痰湿偏重、腹泻期间：库内单味 caution 已多次提示 → 模板须汇总，且体质过滤应偏严（至少阳虚默认不推）。  
- 比单杯麦冬枸杞茶「过凉」风险更高。

#### 为何「中」；落地前要补什么

- 组成可选空间大 → **必须人工钉死一版**，并写明「本站白名单版，≠ 市售料包」。  
- 味数若 ≥5，与茶饮「≤4 味」护栏哲学冲突：模板通道应**独立计数规则**或主动减到 4 味核心 + 1 可选食材。  
- 禁方名：不要写成「益胃汤」「沙参麦冬汤」等经方名；显示名「清补凉（本站白名单版）」即可。

#### 明确不是

不是益胃汤、沙参麦冬汤、增液汤等养阴经方；不是对市售清补凉包的成分鉴定。

### 5. 山楂麦芽消食饮 — 难度 **高**（闸门驱动）

#### 是什么 / 文献要点

食积、油腻、面食停滞之后的消食向家用饮。粤中医局山楂科普有山楂与麦芽配伍类叙述；国家中医药局饮食类发布会语境亦提及麦芽消面食等说法（见文献候选表，作方向支撑，非处方）。

#### 建议组成

| id | 名称 | 在库 | nature | 关键 caution |
|---|---|---|---|---|
| `shanzha` | 山楂 | 是 | warm | 胃酸多/溃疡慎；**孕妇不宜** |
| `maiya` | 麦芽 | 是（pending） | neutral | **哺乳不宜常规推荐**；药典回乳炒用大剂量**禁止**作产品默认 |
| （可选）`jineijin` | 鸡内金 | 是 | neutral | 宜研粉、用量小；可增强消食向，非必须 |

形态上可轻煎或煮饮，最接近「消食茶」，但仍建议走**命名模板**，以便绑死哺乳闸门（自由拼方容易漏闸）。

#### 与泡茶差在哪

- 很接近现有「陈皮山楂消食饮」类茶饮体验；差别主要在 **麦芽**：须煮、且带回乳药典用法阴影。  
- 食材角色仍是饮片；几乎不跨肉类食物表。  
- 开方难度低、**产品责任难度高**——故总档为高。

#### 寒热与体质风险

- 山楂温、麦芽平，整体不极端；胃酸、空腹大量山楂仍不适。  
- **哺乳期**：麦芽回乳是硬问题——不是写一句 caution 就够，应 **规则层排除**（与孕哺空推荐策略对齐或更细：仅禁含麦芽模板）。  
- **孕妇**：山楂库内已不宜 → 含山楂模板应对孕期直接不可荐。  
- 无食积而脾胃弱者不宜久用麦芽（库内 caution）。

#### 为何「高」；落地前要补什么

- 组成与出处不是瓶颈；**不过哺乳/孕期产品闸门就不得上线推荐**。  
- 落地前：`unsuitable` / 高风险筛查必须覆盖 `maiya`；禁止任何「回乳方」用量提示；可选鸡内金时继续小剂量。  
- 显示名可用「山楂麦芽消食饮」；**禁止**挂保和丸、大山楂丸等成药名当家庭煎服指南。

#### 明确不是

不是保和丸，不是消食类中成药说明书复刻，不是门诊消导方加减。
