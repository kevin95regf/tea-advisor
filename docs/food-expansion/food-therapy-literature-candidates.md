## 明确排除（C 层，不进自动推荐）

| 方名 | 原因 |
|---|---|
| 六味地黄丸/汤 | 泽泻、牡丹皮等非食药目录；地黄生熟冲突 |
| 逍遥散 | 柴胡、白芍、白术非目录 |
| 补中益气汤 | 人参/升麻/柴胡等；家用侧只用「芪枣鸡汤取向」 |
| 银翘散 | 连翘、荆芥等非目录；表证须辨证 |
| 小柴胡汤 | 柴胡、黄芩、半夏、人参均不可作食疗主药 |
| 四君子 / 四物 / 二陈 / 桂枝 / 麻黄 | 处方专药为主；麻黄尤峻 |
