# 食材分类歧义清单（营养学审核）

> 来源：`docs/food-expansion/split/food_classification.sidecar.json` 中 `classification_status = 有歧义（见备注）`，且仅含当前运行时 147 条（不含待入库的 79 条）。
> 分类标准：WS/T 464-2015；展示层：中国居民平衡膳食宝塔（2022）。
> 本步**未改**任何 `nature` / `flavors`。运行时已写入的是当前暂定码；本表供营养学裁定后回写。

## 宝塔层说明

- `1`：第一层 谷薯类
- `2`：第二层 蔬菜水果
- `3`：第三层 鱼、禽、肉、蛋等动物性食物
- `4`：第四层 奶类、大豆和坚果
- `5`：第五层 烹调油和盐
- `0`：宝塔外（酒、添加糖、饮料、茶咖啡、调味品、休闲食品等）
- `X`：复合食物（按主料分属多层，见分类侧车 main_ingredients）
