## E9　化橘红与既有 `juhong`（橘红）近似名冲突

> 2026-09-20 评估「扩展第一批 14 味」时产生。与 **D6**（葱拆部位）、**D11**（寿司/咖喱拆子类）
> 不同族：它**不是粒度问题，是「另一个物取了近似的名字」**。

| | |

| **现状** | 饮片表已有 `juhong`（橘红，`herbs.json`）。候选「**化橘红**」是另一物 —— 基源为化州柚的未成熟外层果皮，而橘红为橘类果皮；且化橘红属 **2024 年第 4 号公告**新增的食药物质（同批还有地黄、麦冬、天冬），**带特殊人群使用限定** |

| **验收标准** | 二选一被明确选定；若选 (β)，须验证「说橘红」与「说化橘红」各自只命中一条，且两条的取值的依据分别可查 |
