## 2. 数据来源与方法

通过国家药典委员会「中国药典在线版」的公开只读接口按饮片名检索词条（限定 bookId=1，即 2020 年版一部），再用词条 id 取回正文，从正文里切出【性味与归经】【功能与主治】【用法与用量】。每条都保留了逐字原文、页码与在线链接。可用 `python scripts/build_herb_crosscheck.py --refresh` 复现。

主源：**国家药典委员会「中国药典在线版」公开接口**（《中华人民共和国药典》2020 年版一部），每条都保留了逐字原文与页码。

## 3. 不一致清单（需要你判断以哪个为准）

### 3.1 先看代码：这些字段到底被谁用

判读下面每一条差异的影响之前，先把取证摆出来（用 ripgrep 把所有 `.nature` 读取点列出来核对过）：

**唯一的实质消费者：**

- `nature` → `core/app/agents/agent2_recommend.py:62-66`：把每味候选饮片拼成「- 茯苓（平，甘/淡，归心/肺/脾/肾）」交给 Agent2 —— **这是唯一的实质消费者**。
- `nature` → `core/app/services/matcher.py:156`：规则兜底时把 `nature` 原样拷进 `HerbInBlend` 输出对象。
- `flavors` → `core/app/agents/agent2_recommend.py:63-66`：同上，拼进 Agent2 的候选描述。
- `flavors` → `core/app/services/matcher.py:157`：拷进输出对象。
- `meridians` → `core/app/agents/agent2_recommend.py:66`：同上，拼进 Agent2 的候选描述。
- `meridians` → `core/app/services/matcher.py:158`：拷进输出对象。

**明确没人用的地方（同样重要）：**

- `core/app/domain/safety.py` **完全不读这三个字段**：`check_blend` 只用 `name` / `max_daily_g` / `cautions` / `unsuitable_for`；`check_constitution_fit` 只用 `unsuitable_for`；`filter_by_constitution` 只用 `suitable_constitutions`。
- `core/app/services/matcher.py:134` 的 `match_natures` 匹配的是 **`parsed.overall_nature`（整餐四气，来自 Agent1）**，不是饮片四气。
- **没有任何地方把饮片四气加总成茶饮的四气**，四性数值轴（`nature_math.py`）只作用于食材。
- 两个壳渲染推荐的饮片时都只打印名字/用量/作用：`ui/terminal/chat.py:133-135` 打 `h.name / h.amount_g / h.role`；`ui/web/index.html` 的 `renderRecs` 同理。前端出现的 `f.nature` 是**食材**的四性，不是饮片的。

### 3.2 逐条差异与影响

#### 红枣

- 药典词条：**大枣**（2020 年版一部 p.72）　[在线查看](https://ydz.chp.org.cn/#/item?bookId=1&entryId=30)
- 名称桥接：项目用俗称「红枣」，药典词条为「大枣」
- **药典原文**：甘，温。归脾、胃、心经。
- **项目当前**（按决定保留，未改动）：温／甘／脾、胃
- **差异**：
  - **归经**：项目缺「心」
- **差异影响**：
  - **归经不参与任何运算**：`herbs.json` 的 `_meta.field_notes` 就写明归经是「中文展示用」。项目缺「心」，**确定性逻辑零影响**；唯一后果是 Agent2 看到的脏腑信息少了一味，可能轻微影响它写 `role` 时的用词。
  - **结论**：本处差异**不会改变任何确定性判定结果**，因此「先保留项目值」不会引入功能风险；改动与否取决于中药专业判断。
- 药典【功能与主治】（仅供参照）：补中益气，养血安神。用于脾虚食少，乏力便溏，妇人脏躁。

#### 荷叶

- 药典词条：**荷叶**（2020 年版一部 p.336）　[在线查看](https://ydz.chp.org.cn/#/item?bookId=1&entryId=434)
- **药典原文**：苦，平。归肝、脾、胃经。
- **项目当前**（按决定保留，未改动）：平／苦、淡／肝、脾、胃
- **差异**：
  - **五味**：项目多「淡」
- **差异影响**：
  - **五味不参与任何运算**：五味没有数值编码，既不进护栏也不进规则兜底的选取条件，只出现在 Agent2 的候选描述文字里。项目多「淡」，因此**确定性逻辑零影响**，仅候选描述的文字不同。
  - **结论**：本处差异**不会改变任何确定性判定结果**，因此「先保留项目值」不会引入功能风险；改动与否取决于中药专业判断。
- 药典【功能与主治】（仅供参照）：清暑化湿，升发清阳，凉血止血。用于暑热烦渴，暑湿泄泻，脾虚泄泻，血热吐衄，便血崩漏。荷叶炭收涩化瘀止血。用于出血症和产后血晕。

#### 桑椹

- 药典词条：**桑椹**（2020 年版一部 p.362）　[在线查看](https://ydz.chp.org.cn/#/item?bookId=1&entryId=475)
- **药典原文**：甘、酸，寒。归心、肝、肾经。
- **项目当前**（按决定保留，未改动）：凉／甘、酸／心、肝、肾
- **差异**：
  - **四气**：项目「凉」，药典「寒」（按降档约定应为「寒」）
- **差异影响**：
  - **四性数值轴**：项目 `cool`(-1) → 药典降档后 `cold`(-2)，相差 **1 档**（编码见 `core/app/domain/nature_math.py`）。注意：这条轴**不作用于饮片**，只作用于食材。

  - **对 Agent2 有软性影响**：候选描述里 桑椹 的四性会从「凉」变成「寒」（更偏寒凉），模型据此做寒热搭配推理时可能略微改变选料倾向。这不是硬约束，无法用测试断言。

  - **结论**：本处差异**不会改变任何确定性判定结果**，因此「先保留项目值」不会引入功能风险；改动与否取决于中药专业判断。
- 药典【功能与主治】（仅供参照）：滋阴补血，生津润燥。用于肝肾阴虚，眩晕耳鸣，心悸失眠，须发早白，津伤口渴，内热消渴，肠燥便秘。
