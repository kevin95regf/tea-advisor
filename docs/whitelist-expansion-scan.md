### §0.2 「代茶饮」判据（本项目口径，须你确认）

你给的定义是**泡水喝，不是煎煮**。我据此设了三条判据：

**适合（需全部满足）**：① 语料有性味记载（带行号）；② 无「有毒/有小毒」；③ 无「先煎/久煎/烊化/煨熟去油」硬性前处理；
④ 形态属**花 / 叶 / 全草 / 果实 / 果皮 / 果肉 / 种子（可捣碎）**，**或**语料明载「泡服 / 焗服 / 代茶 / 点汤 / 沸水泡」。

**不适合**：有毒；需先煎久煎或烊化；动物药 / 矿介类；教材明说「主要用作食物调味品」的纯香辛料；须炮制去毒去油。

**待确认**：形态为**根 / 茎 / 木质**、教材仅作「煎服」而无泡服依据者——不是不能泡，是**语料没有泡饮依据**，我不替它定。

> ⚠️ **泡饮量我一条都给不出**（除教材直载泡服者）。下表「常规用量」列一律是**教材【用法用量】的煎服量**，已逐条标 `煎服` 字样；泡饮专用量属待确认项，见 §4.3。

## §6 三点最需要你复核的

**① 化橘红与已收录的「橘红」可能重复。** 七版:4857 把化橘红列为橘皮条下的附药（基源：化州柚或柚的未成熟外层果皮），与药典「橘红」不同源。项目 `catalog-compliance.md` 已把「橘红→桔红」判为在目录内；2024 年第 4 号新增的「化橘红」是**另一个**条目。是否单列须你定。

**② 「地黄」在目录里没写生熟。** 生地黄甘苦寒（清热凉血），熟地黄甘微温（补血滋阴）——**性味相反**。我用七版:2515 的生地黄条目，若项目要的是熟地黄，结论反过来。

**③ §3.2 的配伍禁忌大多是「空转」。** 藜芦、人参、郁金、赤石脂都不在 106 目录内，纯目录场景触发不了。**唯一现实的是「莱菔子 × 人参」**：莱菔子若入选，需在未来收录人参或用户自服人参时能拦。请确认项目是否有「用户自服药清单」这个输入口。
