# 中医九种体质问卷（GB/T 46939-2025）

这是一个可直接运行、零第三方 Python 依赖的中医体质筛查工具。题目、五级评分、转化分公式和判定阈值来自现行国家推荐标准 **GB/T 46939-2025《中医体质分类与判定》**。

> 重要纠正：权威标准不是“五大体质”，而是 **九种基本体质**：平和质，以及气虚质、阳虚质、阴虚质、痰湿质、湿热质、血瘀质、气郁质、特禀质八种偏颇体质。“五行体质”等五分类方法目前没有与 GB/T 46939-2025 同等层级、统一题目和统一计分规则的国家标准。

## 快速开始

要求 Python 3.10 或更高版本，无需安装第三方包。

```bash
python -m tcm_constitution
```

也可以读取 JSON，并把完整结果写出：

```bash
python -m tcm_constitution \
  --input examples/answers_balanced.json \
  --output result.json
```

运行测试：

```bash
python -m unittest discover -s tests -v
```

可选安装为命令：

```bash
python -m pip install -e .
tcm-constitution
```

## 问卷与计分

完整纸面版见 [QUESTIONNAIRE.md](QUESTIONNAIRE.md)，机器可读表格见 [questionnaire.csv](questionnaire.csv)。

- 回答近一年的体验和感觉。
- 每题按 1–5 评分：没有、很少、有时、经常、总是。
- 附录按分量表列出 30 个计分条目，其中 3 个问题在两个分量表中重复，因此题库共有 27 个不同问题。湿热质的两个性别限定题只答其一，所以每位用户实际回答 26 题；计分时会复用 3 个共享问题的答案。
- 湿热质含一个女性限定题和一个男性限定题；一次测评只采用其中一个，因此湿热质实际计 3 项。
- 转化分：`[(原始分 - 条目数) / (条目数 × 4)] × 100`。
- 平和质和八种偏颇体质分别判定，允许兼夹体质，不应强制只取一个最高分。

### 标准判定阈值

| 类型 | 条件 | 判定 |
|---|---|---|
| 平和质 | 转化分 ≥ 60，且其余 8 种体质均 < 30 | 是 |
| 平和质 | 转化分 ≥ 60，且其余 8 种体质均 < 40 | 基本是 |
| 平和质 | 不满足以上条件 | 否 |
| 任一偏颇体质 | 转化分 ≥ 40 | 是 |
| 任一偏颇体质 | 30 ≤ 转化分 ≤ 39（程序按连续分值实现为 `30 ≤ 分数 < 40`） | 倾向是 |
| 任一偏颇体质 | 转化分 < 30 | 否 |

结果 JSON 中的 `ranking_nonstandard` 只是便于展示的分数排序，不是国标规定的“唯一主导体质”诊断。

## JSON 格式

```json
{
  "sex": "female",
  "answers": {
    "q01": 5,
    "q02": 1
  }
}
```

`sex` 取 `female` 或 `male`，只用于选择湿热质的性别限定题。答案键和值的完整示例见 [examples/answers_balanced.json](examples/answers_balanced.json)。

## 权威性与证据

1. 国家市场监督管理总局/国家标准委的[标准信息页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=827D6D266BA52A2983F93638DA871028)显示，GB/T 46939-2025 于 2025-12-31 发布、2026-04-01 实施，主管和归口部门均为国家中医药局。
2. 市场监管总局的[发布说明](https://www.samr.gov.cn/xw/sj/art/2026/art_bbc0d96fbbb741a2a66d2f4f7a44fd82.html)明确标准规定九种基本类型，并采用典型体感问题及等级计分算法。
3. Bai 等在 *Chinese Medicine* 发表的[短版量表开发与评价研究](https://doi.org/10.1186/s13020-023-00844-3)采用专家调查、经典测量理论与项目反应理论开发短版；最佳版本在结构效度、效标效度、重测信度和内部一致性方面表现最佳，平和质 ROC AUC 为 0.928，八种偏颇体质在原量表阈值下的 AUC 范围为 0.895–0.981。

## 适用边界

- 这是体质筛查和健康教育工具，不是疾病诊断工具，也不生成处方或治疗建议。
- 自评问卷不能替代中医师的望、闻、问、切和临床判断。
- 性别限定题沿用国标原有表述。对于不适用或无法确定的情况，不应强行生成完整的湿热质结论，建议由专业人员结合实际解读。
- 本程序默认仅在本地处理答案；是否保存结果由运行者决定。健康答案属于敏感数据，上传或公开前应去标识化。
